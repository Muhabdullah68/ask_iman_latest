### 🔴 Why You Can't See Theme Changes Clearly (Root Causes)
1. Mobile-First Orientation Lock — main.dart lines 27-30 forces portrait only. Web needs responsive!
2. web/index.html is boilerplate — No proper PWA setup, no SEO, no dark-mode CSS vars
3. No web-specific responsive breakpoints — App designed for 360×800, web is 1280×720+
4. No web routing / URL deep links — Routes not mapped to browser history
5. Mobile-only plugins have limited web support — Compass, Vibration, Geolocator
